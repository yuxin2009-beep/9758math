User Guide How to Use This Interactive Visual Lab
1. Select a Shifted-Line Problem (Top-Left) Choose a region bounded directly by a curve and a shifted horizontal line y = k or vertical line x = k (no washers—pure single-curve solids!).
2. Slide Translation Progress (0% → 100%) Drag the Translation Shift (−k) slider (or click Animate Shift → Axis) to watch both the curve and the line y = k (or x = k) translate onto the coordinate axis!
3. Revolve Around the Axis & Check Exam Quiz Once translated onto the axis (Y = 0 or X = 0), use the standard disc formula π∫ Y² dx or π∫ X² dy, then test yourself on the 3-question 9758 Exam Check.
