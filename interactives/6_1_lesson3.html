1. Addition Law & Complements
• P(A ∪ B) = P(A) + P(B) − P(A ∩ B).
• P(A′ ∩ B′) = 1 − P(A ∪ B) (neither occurs).
• P(A′ ∪ B′) = 1 − P(A ∩ B) (not both occur).
2. Independence vs. Mutually Exclusive
• Independent: P(A ∩ B) = P(A) × P(B).
• Mutually Exclusive: P(A ∩ B) = 0 (disjoint circles).

9758 Exam Misconception Alert — Two Key Traps:
  • "Mutually Exclusive" ≠ "Independent": If P(A) > 0 and P(B) > 0 and P(A ∩ B) = 0, they can NEVER be independent because P(A)P(B) > 0 ≠ 0.
  • Finding Max/Min Bounds of a Probability: Never rely on 0 ≤ P(B) ≤ 1 alone! Every individual disjoint region inside the Venn diagram (such as B only = 3b/4 − 1/8 and C only = 3/5 − 3b/4) must satisfy 0 ≤ P(region) ≤ 1.
