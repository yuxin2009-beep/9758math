9758 Misconception Alert (Derivations & Proving AP/GP):
  • Never prove a sequence is an AP or GP using specific numbers: Checking u₂ − u₁ = u₃ − u₂ (or u₂/u₁ = u₃/u₂) only tests the first 3 terms! You must show algebraically for all n ∈ ℤ⁺ that u_{n+1} − u_n = constant (for AP) or u_{n+1} / u_n = non-zero constant (for GP), independent of n.
  • Recovering u_n from a given S_n expression: Always compute u_n = S_n − S_{n−1} for n ≥ 2, and verify separately whether n = 1 (u₁ = S₁) obeys the same formula!
