1.3 Lesson 2 • Modulus Properties & Inequalities
Core Properties of Modulus |x| Hide Δ
• |x| ≥ 0 for all x ∈ ℜ
• |x|² = x²
• |ab| = |a| |b|
• |a / b| = |a| / |b| (b ≠ 0)
• |x| < a ⇔ −a < x < a (a > 0)
• |x| > a ⇔ x < −a or x > a

9758 Misconception Alert (Modulus Inequalities):
  • When is squaring both sides valid? You may square both sides of |f(x)| < |g(x)| because both sides are guaranteed non-negative. Never blindly square |ax + b| > cx + d without checking whether cx + d < 0!
  • In "Hence deduce" parts: Remember that |x| ≥ 0 and x² ≥ 0 always. Any negative portion of the earlier interval (such as −3 < |x| < 2) automatically simplifies to 0 ≤ |x| < 2.
