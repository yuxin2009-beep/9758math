9758 Misconception Alert (Algebraic vs. Graphical Modulus Methods):
  • Rule of thumb for choosing methods:
    • For |ax + b| < k (constant k > 0): use −k < ax + b < k directly.
    • For |ax + b| < |cx + d|: square both sides (valid since both sides are ≥ 0) and factorise via A² − B² = (A − B)(A + B).
    • For |ax + b| < cx + d: either use two-sided compound inequality −(cx + d) < ax + b < cx + d (which automatically forces cx + d > 0!) or sketch both graphs to reject spurious intersections where cx + d < 0.
