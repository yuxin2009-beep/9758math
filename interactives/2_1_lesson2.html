User Guide How to Use This Interactive Visual Lab
1. Choose a Recurrence Behavior Preset (Top-Left) Compare Monotonic Convergence, Oscillating Spiral, Divergent Blow-Up, and Periodic 2-Cycle to see how u_{n+1} = f(u_n) evolves over time.
2. Adjust Initial Value u₁ & Step Count n Drag the Initial Term (u₁) and Steps (N) sliders to trace the vertical-to-horizontal cobweb staircase between y = f(x) and y = x, while inspecting the live TI-84 style sequence table.
3. Verify the Limit Equation L = f(L) Check the green Limit Analysis banner: even when L = f(L) has algebraic roots, a sequence only converges to L if |f'(L)| < 1 (otherwise it diverges or cycles!).

9758 Misconception Alert (Recurrence Limits):
  • Never solve L = f(L) without first checking convergence! In Preset 3 (u_{n+1} = 1.35u_n − 1), solving L = 1.35L − 1 gives L = 2.86, yet u_n → ±∞ unless u₁ = 2.86 exactly!
  • Always state: "As n → ∞, u_n → L and u_{n+1} → L" before substituting L into the recurrence relation.
