User Guide How to Use This Interactive Visual Lab
1. Select a Function Type (Top-Left) Switch between Quadratic, Rational, and Circle Relation to see how domain restrictions shape the graph and test whether a rule is a valid function.
2. Adjust Domain Endpoints & Bracket Types Drag the x_min and x_max sliders and toggle open ( ) vs. closed [ ] endpoints to watch the green range projection on the y-axis update live.
3. Run the Vertical Line Test Drag the Vertical Test Line x slider across the graph—if the vertical line cuts the curve more than once (as in the Circle Relation), it is not a function.
