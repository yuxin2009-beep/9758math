User Guide How to Use This Interactive Visual Lab
1. Adjust Domain D_f and Domain D_g Move the sliders on the left to change the input interval D_f = [a, b] of f(x) = x² − 1 and the permitted domain D_g = [c, ∞) of g(x) = √(x − c).
2. Inspect the Two-Stage Pipeline (D_f → R_f → R_{gf}) Watch the middle number line on the canvas: if the purple bar R_f fits completely inside the blue bar D_g (R_f ⊆ D_g), then gf exists!
3. Compare R_{gf} Against R_g Notice on the right-hand number line how R_{gf} is computed by feeding only R_f (not all of D_g) into g.

9758 Misconception Alert (Composite Functions):
  • Existence condition R_f ⊆ D_g: Always state both sets explicitly (e.g., R_f = [−1, 8] ⊆ [−2, ∞) = D_g) when justifying why gf exists.
  • Range of gf is NOT R_g: To find R_{gf}, restrict the input of g to R_f (not all of D_g).
