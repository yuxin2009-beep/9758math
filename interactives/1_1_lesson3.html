User Guide How to Use This Interactive Visual Lab
1. Adjust Domain Df and Domain Dg Move the sliders on the left to change the input interval Df = [a, b] of f(x) = x² − 1 and the permitted domain Dg = [c, ∞) of g(x) = √x − c.
2. Inspect the Pipeline (Df → Rf → Rgf) Watch the middle number line on the canvas: if the purple bar Rf fits completely inside the blue bar Dg (Rf ⊆ Dg), then gf exists!
3. Compare Rgf Against Rg Notice on the right-hand number line how Rgf is computed by feeding only Rf (not all of Dg) into g.

9758 Misconception Alert (Composite Functions):
  • Existence condition Rf ⊆ Dg: Always state both sets explicitly (e.g., Rf = [−1, 8] ⊆ [−2, ∞) = Dg) when justifying why gf exists.
  • Range of gf is NOT Rg: To find Rgf, restrict the input of g to Rf (not all of Dg).
