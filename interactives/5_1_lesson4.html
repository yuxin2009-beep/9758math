User Guide How to Use This Interactive Visual Lab
1. Adjust Parameter or Click a Curve Point Choose between a Parametric Ellipse ($x = a\cos\theta, y = b\sin\theta$), a Parametric Reciprocal Curve ($x = t + \frac{1}{t}, y = t - \frac{1}{t}$), or an Implicit Hyperbola ($\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$).
2. Inspect Tangent, Normal & Area of $\triangle OAB$ Watch the solid Tangent and dashed Normal update in real time (plotted on a 1:1 isotropic scale so perpendicularity is exact) along with their intercepts ($A, B$) and the area of $\triangle OAB$.
3. Test Horizontal & Vertical Tangent Edge Cases Click the quick-jump buttons to snap to vertices where $\dfrac{\mathrm{d}y}{\mathrm{d}x} = 0$ (horizontal tangent $y = y_0$; vertical normal $x = x_0$) or $\dfrac{\mathrm{d}x}{\mathrm{d}t} = 0$ (vertical tangent $x = x_0$; horizontal normal $y = y_0$).

1. Draw Tangent in FUNC Mode
Plot Y₁ = f(x), press [2nd] [PRGM] (DRAW) → 5: Tangent(, type $x = x_0$, and press [ENTER].
2. Gradient in PARAM Mode
Switch [MODE] → PARAM, enter X₁T, Y₁T, and press [2nd] [TRACE] → 2: dy/dx at $T = t_0$.
3. Normal Gradient $m_N$
Compute $m_N = -\dfrac{1}{m_T}$ when $m_T \neq 0$. If $m_T = 0$, the normal is $x = x_0$; if $m_T$ is undefined, the normal is $y = y_0$.
9758 Exam Misconception Alert:
  • Substitute $t = t_0$ BEFORE writing line equations: Never write $y - y_0 = f'(t)(x - x_0)$ with $t$ still inside the gradient—always substitute the numerical value $t = t_0$ into $\dfrac{\mathrm{d}y}{\mathrm{d}x}$ first.
  • Never divide by zero for normals: When $\dfrac{\mathrm{d}y}{\mathrm{d}x} = 0$ (horizontal tangent $y = y_0$), do not write $m_N = -\frac{1}{0}$; state directly that the normal is the vertical line $x = x_0$.
