3.3 Lesson 2 • Relationship & Angle Between Line and Plane in 3D
Three Possible Relationships Between a Line L and a Plane Π
9758 Misconception Alert (Line & Plane Relationship & Angle):
  • Use sin θ (NOT cos θ) for the Angle Between a Line and a Plane: The dot product |d · n| / (|d||n|) gives cos α, where α is the acute angle between line direction d and plane normal n. Since normal n is perpendicular to the plane, the acute angle θ between the line and the plane is the complement θ = 90° − α, so sin θ = |d · n| / (|d||n|)!
  • Substituting r = a + λd into r · n = D Gives 0λ = k when d · n = 0: If d · n = 0, the line is parallel to the plane. Check a · n: if a · n ≠ D, you get 0λ = D − a · n ≠ 0 (no solution ⇒ strictly parallel); if a · n = D, you get 0λ = 0 (infinitely many solutions ⇒ line lies completely inside the plane).
