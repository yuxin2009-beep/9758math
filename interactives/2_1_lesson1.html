2.1 Lesson 1 • Sequences as f(n), uₙ vs Sₙ & Series Sums
Sequence as a Function: uₙ = f(n), n ∈ ℤ⁺
9758 Misconception Alert (General Sequences & Series):
  • Discrete domain n ∈ ℤ⁺: A sequence uₙ = f(n) is defined only at positive integers n = 1, 2, 3, … Never join sequence points with a continuous curve!
  • Always check u₁ = S₁ separately: The formula uₙ = Sₙ − Sₙ₋₁ is valid only for n ≥ 2 (since S₀ is undefined). When Sₙ has a non-zero constant term (e.g. Sₙ = n² + 2n + 3), u₁ = S₁ will not match the n ≥ 2 formula, so your final answer for uₙ must be written piecewise!
