User Guide How to Use This Interactive Visual Lab
1. Pick a Function Preset (Top-Left) Compare Restricted Quadratic, Rational Function, and Exponential Function to test one-one behaviour and view the inverse rule f−1(x).
2. Restrict Domain to Make f One-One Drag the left domain endpoint a on the Quadratic preset across the turning point x = 1. Notice how f−1 exists if and only if a ≥ 1!
3. Run Horizontal Line Test & Reflection Slide y = k vertically to check for at most 1 intersection, and toggle the y = x reflection to see (x, y) ↔ (y, x).

  • Proving f is one-one: Sketch y = f(x) over Df and state: "Every horizontal line y = k cuts the graph of y = f(x) at most once; hence f is one-one and f−1 exists."
  • Domain of f−1 = Range of f (Df−1 = Rf): Always state both the rule f−1(x) and its domain x ∈ Rf when defining f−1.
