User Guide How to Use This Interactive Visual Lab
1. Select a Parametric Curve Family (Top-Left) Choose between 1. Parabola (t), 2. Trig Ellipse (θ), and 3. Restricted Arc (θ ∈ [0, π]) to see how parameter intervals govern the traced curve.
2. Scrub the Parameter Slider (t or θ) Drag the parameter slider to move the red tracer particle along the curve and read its live (x(t), y(t)) coordinates and direction of motion.
3. Compare Cartesian Form vs. Parameter Domain In Mode 3, notice how restricting θ ∈ [0, π] traces only the upper semi-ellipse even though the Cartesian equation is a full ellipse!

9758 Misconception Alert (Parametric Curves):
  • Always restrict the Cartesian curve to the parameter domain: Eliminating θ from x = 4 cos θ, y = 3 sin θ gives x²/16 + y²/9 = 1, but if 0 ≤ θ ≤ π, then y = 3 sin θ ≥ 0, so only the upper half exists!
  • Use trigonometric identities (cos²θ + sin²θ = 1) instead of inverse trig: Never write θ = cos⁻¹(x/4) when converting trig parametrics to Cartesian form.
