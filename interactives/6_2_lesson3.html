6.2 Lesson 3 Linear Transformations & Fair Games: E(aX + b) & Var(aX + b)

Observe how scaling by a and shifting by b affect E(Y) and Var(Y), and solve fair-game entry fee problems.

1. Base Distribution X
Base Variable X: Outcomes {1, 2, 4, 7} with probabilities {0.2, 0.3, 0.3, 0.2}
E(X) = 3.40 • Var(X) = 4.44 • σ_X = 2.1071
2. Quick 9758 Transformation Presets
Scale Multiplier a: a = 1.0
Constant Shift b: b = +5.0
9758 Pitfall Check:
• Adding b shifts the location (mean), NOT the spread: Var(aX + b) = a²Var(X) (no + b!).
• When a < 0, variance stays positive because a² > 0, and σ_Y = |a|σ_X.
