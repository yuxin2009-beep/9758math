Three Equivalent Forms of a Plane Π in 3D Space
9758 Misconception Alert (Equations of Planes & Point Membership):
  • Parametric Plane Needs TWO Non-Parallel Direction Vectors: A plane has 2 degrees of freedom (r = a + λd₁ + μd₂, where d₁ ∦ d₂); using only one parameter λ defines a 1D line, not a 2D plane!
  • Testing Point Membership on Parametric vs. Scalar Product Form: If the plane is given in scalar product or Cartesian form (r · n = D), simply substitute OP into r · n and check if it equals D (one line!). If given in parametric form, solve the x and y equations for (λ, μ) and verify consistency in the 3rd equation (z).
