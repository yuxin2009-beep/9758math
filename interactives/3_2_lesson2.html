Foot of Perpendicular N from Point P to Line L in 3D
9758 Misconception Alert (Point-to-Line Foot & Perpendicular Distance):
  • Always check whether the question asks for Foot N or Distance d: If you only need the perpendicular distance from P to L, the cross-product formula d = |AP × d̂| = |AP × d| / |d| finds it in one step without solving for λ. However, if you need the coordinates of Foot N or Reflection P′, you must use the dot product condition PN · d = 0 (or projection AN = (AP · d̂)d̂).
  • Use PN · d = 0, NOT ON · d = 0: The vector perpendicular to the line is PN = ON − OP (joining P to N), not the position vector ON from the origin!
