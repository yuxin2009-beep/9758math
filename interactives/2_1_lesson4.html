2.1 Lesson 4 • Sum to Infinity S∞ & Real-World Applications
Derivation of GP Sum to Infinity S∞ (when |r| < 1):
1. Start with the finite GP partial sum (for r ≠ 1):  S_n = a(1 − r^n) / (1 − r).
2. When −1 < r < 1 (i.e. |r| < 1), as n → ∞, r^n → 0.
3. Therefore,  S∞ = lim_{n→∞} S_n = a(1 − 0) / (1 − r) = a / (1 − r).

9758 Misconception Alert (Sum to Infinity & Applications):
  • Bouncing ball initial drop is NOT doubled: A ball dropped from height H travels H downward once, then travels 2Hr + 2Hr² + ... (both up and down) on subsequent rebounds: D∞ = H + 2Hr / (1 − r) = H(1 + r) / (1 − r).
  • Sign flip when taking logarithms: When solving r^n < k for 0 < r < 1, taking ln gives n ln r < ln k; since ln r < 0, dividing by ln r reverses the inequality to n > (ln k) / (ln r)!
