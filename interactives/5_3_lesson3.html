MF27 Standard Quadratic Integrals (Divide by p when u = px + q) Watch Signs & √ Carefully: One Sign Flips tan−1 ↔ ln!
∫ 1x² + a² dx = 1a tan−1(xa) + C
Sum of squares, no √ → tan−1 with 1a outside.
∫ 1a² − x² dx = sin−1(xa) + C
With √, a² − x² → sin−1 (no 1a in front!).
∫ 1x² − a² dx = 12a ln|x − ax + a| + C
Variable first (x² − a²), no √ → x − a on top.
∫ 1a² − x² dx = 12a ln|a + xa − x| + C
Constant first (a² − x²), no √ → a + x on top.

Tab 2: Linear Numerator Splitting (Ax + B → k·f′(x) + R)
2-Part Numerator Decomposition Blueprint
Case A: Denominator Without Square Root (Ax + Bf(x))
1. Compute f′(x) of the quadratic denominator.
2. Write Ax + B = k · f′(x) + R by matching the x-coefficient first.
3. Integrate k ∫ f′(x)f(x) dx = k ln|f(x)| and complete the square on R ∫ 1f(x) dx for MF27!
Case B: Denominator With Square Root (Ax + Bf(x))
1. Write Ax + B = k · f′(x) + R.
2. First part uses power rule n = −½:
k ∫ f′(x)[f(x)]−½ dx = k · [f(x)]½½ = 2kf(x)
3. Second part R ∫ 1a² − u² dx integrates to R sin−1(ua)!
Tab 3: Partial Fractions Decomposition & Integration
Partial Fraction Templates & Common Traps
1. Check Properness First!
If deg(Numerator) ≥ deg(Denominator), perform polynomial long division before setting up partial fractions.
2. Three Standard Denominator Templates:
• Distinct linear (ax + b)(cx + d): Aax + b + Bcx + d
• Repeated linear (ax + b)²: Aax + b + B(ax + b)²
• Irreducible quadratic (x² + a²): Bx + Cx² + a² (split into ln + tan−1!)
Repeated Factor Trap: ∫ 1(x + 1)² dx = ∫ (x + 1)−2 dx = −1x + 1 + C (Power rule n = −2, NEVER ln|(x + 1)²|!).
