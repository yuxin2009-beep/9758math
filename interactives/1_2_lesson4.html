User Guide How to Use This Interactive Visual Lab
1. Choose a Transformation Family (Top-Left) Switch between 1. Translations, 2. Scalings & Reflections, and 3. Sequence Order to compare how changes to x vs. y affect the base curve y = f(x).
2. Adjust Parameters & Track Key Points Drag the sliders to shift or stretch the purple transformed curve relative to the dashed grey base curve, tracking how the stationary point and asymptote move.
3. Compare Transformation Order (Mode 3) In Mode 3, toggle between Translate First → Scale Second vs. Scale First → Translate Second to see why the order of horizontal operations changes the final equation!

9758 Misconception Alert (Graph Transformations):
  • Horizontal changes act inversely: Replacing x with x − 2 shifts the graph 2 units in the positive x-direction; replacing x with 2x scales parallel to the x-axis by factor 1/2 (not 2!).
  • Always factor out the coefficient of x when reading horizontal sequences: For y = f(2x − 6) = f(2(x − 3)), translating 6 units right then scaling by 1/2 yields x → x − 6 → 2x − 6, whereas scaling by 1/2 first requires translating by 3 units right!
