2.1 – 2.3 Key Identities & Rules

Quadratics, Polynomials, Partial Fractions & Logs

Quadratics (ax2 + bx + c = 0, a ≠ 0):
• Sum of roots: α + β = −b/a; Product: αβ = c/a.
• Discriminant Δ = b2 − 4ac: Δ > 0 (2 real distinct), Δ = 0 (equal), Δ < 0 (no real roots).
• Always positive: a > 0 and b2 − 4ac < 0.
Standard Factorisations:
• a2 − b2 = (a + b)(a − b)
• a3 − b3 = (a − b)(a2 + ab + b2)
• a3 + b3 = (a + b)(a2 − ab + b2)
Partial Fractions (Check deg P < deg Q first!):
• Linear: Aax + b  |  Repeated: Bcx + d + C(cx + d)2  |  Irreducible quadratic: Bx + Cx2 + c2.
Exponentials & Logarithms (a > 0, a ≠ 1):
• y = ax ⇔ x = loga y;  x = eln x;  Change of base: loga b = ln bln a.

4. 2D Vectors (Assumed Knowledge — Chapter 1: Basics)

Sections 4.1 – 4.10
Sub-section & Concept Key Definitions, Forms & Laws Key Notes & Geometric Meaning
4.1 – 4.3 Scalars, Position & Free Vectors Scalars: Magnitude only (distance, speed, mass, time, area, volume, temperature).
Vectors: Magnitude & direction (displacement, velocity, weight, force).
Position vector: $\overrightarrow{OP}$ locates $P$ relative to origin $O$.
Free (displacement) vector: $\mathbf{a} = \overrightarrow{PQ}$ (initial $P$, terminal $Q$), no fixed position. 		Any displacement vector can be written in terms of position vectors of its endpoints:
$\overrightarrow{PQ} = \overrightarrow{OQ} - \overrightarrow{OP}$
4.4 – 4.6 2D Column Form, Magnitude, Negative & Zero Vectors Column & $\mathbf{i}, \mathbf{j}$ form: $\overrightarrow{PQ} = \begin{pmatrix} a \\ b \end{pmatrix} = a\mathbf{i} + b\mathbf{j}$
Magnitude: $|\overrightarrow{PQ}| = \sqrt{a^2 + b^2}$
Negative vector: $-\overrightarrow{PQ} = \overrightarrow{QP} = \begin{pmatrix} -a \\ -b \end{pmatrix}$
Zero (null) vector: $\mathbf{0} = \begin{pmatrix} 0 \\ 0 \end{pmatrix} = \overrightarrow{PP}$ 		$\mathbf{i}$ and $\mathbf{j}$ are unit vectors in the $x$- and $y$-directions.
$|\overrightarrow{PQ}| = |\overrightarrow{QP}|$ (same length, opposite direction).
$\mathbf{a} + \mathbf{0} = \mathbf{a}$ and $\mathbf{a} + (-\mathbf{a}) = \mathbf{0}$.
4.7 Vector Addition & Subtraction Algebraic: $\begin{pmatrix} a \\ b \end{pmatrix} \pm \begin{pmatrix} c \\ d \end{pmatrix} = \begin{pmatrix} a \pm c \\ b \pm d \end{pmatrix}$
Triangle Law (Head-to-Tail): $\overrightarrow{AB} + \overrightarrow{BC} = \overrightarrow{AC}$
Parallelogram Law ($OACB$):
$\overrightarrow{OA} + \overrightarrow{OB} = \overrightarrow{OC} = \mathbf{a} + \mathbf{b}$
$\overrightarrow{OA} - \overrightarrow{OB} = \overrightarrow{BA} = \mathbf{a} - \mathbf{b}$ 		In parallelogram $OACB$, $\mathbf{a}+\mathbf{b}$ and $\mathbf{a}-\mathbf{b}$ represent the two diagonals $\overrightarrow{OC}$ and $\overrightarrow{BA}$.
4.8 Scalar Multiplication & Parallel Vectors $k\begin{pmatrix} a \\ b \end{pmatrix} = \begin{pmatrix} ka \\ kb \end{pmatrix}$, with magnitude $|k\mathbf{a}| = |k||\mathbf{a}|$.
Parallel condition: For non-zero $\mathbf{a}, \mathbf{b}$,
$\mathbf{a} \parallel \mathbf{b} \iff \mathbf{a} = \lambda\mathbf{b}$ for some $\lambda \in \mathbb{R} \setminus \{0\}$. 		• $\lambda > 0$: same direction as $\mathbf{a}$
• $\lambda < 0$: opposite direction to $\mathbf{a}$
• $\lambda = 0$: gives zero vector $\mathbf{0}$
4.9 – 4.10 Laws of Vector Algebra & Equal Vectors Commutative: $\mathbf{a}+\mathbf{b}=\mathbf{b}+\mathbf{a}$, $\lambda\mathbf{a}=\mathbf{a}\lambda$
Associative: $(\mathbf{a}+\mathbf{b})+\mathbf{c}=\mathbf{a}+(\mathbf{b}+\mathbf{c})$, $(\lambda\mu)\mathbf{a}=\lambda(\mu\mathbf{a})$
Distributive: $(\lambda+\mu)\mathbf{a}=\lambda\mathbf{a}+\mu\mathbf{a}$, $\lambda(\mathbf{a}+\mathbf{b})=\lambda\mathbf{a}+\lambda\mathbf{b}$
Equal vectors: $\begin{pmatrix} p \\ q \end{pmatrix} = \begin{pmatrix} r \\ s \end{pmatrix} \iff p=r \text{ and } q=s$. 		Equal vectors require both equal magnitude and identical direction (e.g. in parallelogram $ABCD$, $\overrightarrow{AB} = \overrightarrow{DC}$ and $\overrightarrow{AD} = \overrightarrow{BC}$).
Core Geometric Application (Ratio of Triangle Areas): When two triangles share the same perpendicular height $h$ along a common base line (e.g. $\overrightarrow{QT} = \frac{3}{4}\overrightarrow{QS}$), the ratio of their areas equals the ratio of their base lengths: $\dfrac{\text{Area of }\triangle PQT}{\text{Area of }\triangle PQS} = \dfrac{\frac{1}{2}(QT)h}{\frac{1}{2}(QS)h} = \dfrac{QT}{QS} = \dfrac{3}{4}$.
5.1 – 5.3 Properties & Graph Sketching

Absolute Value |f(x)| Rules

Definition: |x| = x if x ≥ 0, and −x if x < 0.
• |xy| = |x||y|;  |x/y| = |x|/|y| (y ≠ 0)
• |x2| = |x|2 = x2;  √(x2) = |x|
• For a > 0: |x| = a ⇔ x = ±a.
Sketching y = |f(x)|:
Retain the portion of y = f(x) on or above the x-axis (f(x) ≥ 0), and reflect the portion below the x-axis (f(x) < 0) upward across the x-axis (forming sharp corners at x-intercepts).

6.1 – 6.2 Differentiation & Stationary Points

Product Rule, Quotient Rule & Nature Tests

Product Rule: ddx(uv) = u dvdx + v dudx

Quotient Rule: ddx(uv) = v dudx − u dvdxv2
Stationary Points (dydx = 0):
• Local Maximum: d2ydx2 < 0 (or gradient changes + → 0 → −).
• Local Minimum: d2ydx2 > 0 (or gradient changes − → 0 → +).
• Stationary Point of Inflexion: gradient keeps same sign across stationary point.
