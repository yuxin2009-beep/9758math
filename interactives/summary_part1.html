2.1 – 2.3 Key Identities & Rules

Quadratics, Polynomials, Partial Fractions & Logs

Quadratics (ax2 + bx + c = 0, a ≠ 0):
• Sum of roots: α + β = −ba;  Product of roots: αβ = ca.
• Discriminant Δ = b2 − 4ac: Δ > 0 (2 real distinct), Δ = 0 (equal), Δ < 0 (no real roots).
• Always positive: a > 0 and b2 − 4ac < 0.
Standard Factorisations:
• a2 − b2 = (a + b)(a − b)
• a3 − b3 = (a − b)(a2 + ab + b2)
• a3 + b3 = (a + b)(a2 − ab + b2)
Partial Fractions (Check deg P < deg Q first!):
• Linear: Aax + b  |  Repeated: Bcx + d + C(cx + d)2  |  Irreducible quadratic: Bx + Cx2 + c2.
Exponentials & Logarithms (a > 0, a ≠ 1):
• y = ax ⇔ x = loga y;  x = eln x;  Change of base: loga b = ln bln a.
Worked Example — Completing the Square & Discriminant Section 2.1
(a) By completing the square, (i) show that 2x2 − 3x + 2 is always positive; (ii) find the minimum value of 2x2 + 2x + 3 and deduce the range of 12x2 + 2x + 3.
(b) (i) Find k if the roots of 3x2 + kx + 12 = 0 are equal. (ii) Show that the roots of ax2 + (a + b)x + b = 0 are real for all non-zero a, b.
(a)(i) 2x2 − 3x + 2 = 2(x − 34)2 + 78. Since (x − 34)2 ≥ 0 for all x ∈ ℝ, the expression is ≥ 78 > 0 (always positive).
(a)(ii) 2x2 + 2x + 3 = 2(x + 12)2 + 52 ⇒ minimum value is 52. Hence 2x2 + 2x + 3 ≥ 52 ⇒ range of reciprocal is (0, 25].
(b)(i) Equal roots ⇒ k2 − 4(3)(12) = 0 ⇒ k2 = 144 ⇒ k = ±12.
(b)(ii) Discriminant Δ = (a + b)2 − 4ab = a2 − 2ab + b2 = (a − b)2 ≥ 0 for all a, b ∈ ℝ ⇒ roots are always real.
Worked Example — Polynomial Division, Factorisation & Partial Fractions Section 2.2
(a) Find the quotient and remainder when x3 + 3x2 − 6x + 2 is divided by x + 2, and factorise x3 − 2x + 1 completely.
(b) Factorise completely: (i) x3 + 8; (ii) x6 − 64.
(c) Express in partial fractions: (i) 2xx2 − 1; (ii) 3x2 + 3x + 2(x + 1)(x2 + 1); (iii) 11 − x − x2(x + 2)(x − 1)2; (iv) 2x2 + 6x − 5(x − 1)(x + 2).
(a) Long division gives quotient x2 + x − 8 and remainder 18. For f(x) = x3 − 2x + 1, f(1) = 0 ⇒ (x − 1) is a factor; dividing gives (x − 1)(x2 + x − 1) = (x − 1)(x − −1 + √52)(x − −1 − √52).
(b)(i) x3 + 23 = (x + 2)(x2 − 2x + 4).
(b)(ii) (x3 − 8)(x3 + 8) = (x − 2)(x2 + 2x + 4)(x + 2)(x2 − 2x + 4).
(c)(i) 1x − 1 + 1x + 1.
(c)(ii) 1x + 1 + 2x + 1x2 + 1.
(c)(iii) 1x + 2 − 2x − 1 + 3(x − 1)2.
(c)(iv) Improper (deg 2 / deg 2): 2 + 4x − 1(x − 1)(x + 2) = 2 + 1x − 1 + 3x + 2.
Worked Example — Logarithmic Equations & Standard Graph Features Section 2.3
(a) Solve in exact form: (i) logx(3x − 2) = 2; (ii) (3x)ln 3 = (4x)ln 4.
(b) State the axial intercepts and equations of asymptotes for y = 2x, y = log2 x, y = e−x, and y = 110x.
(a)(i) x2 = 3x − 2 ⇒ (x − 1)(x − 2) = 0. Since base x > 0, x ≠ 1, x = 2.
(a)(ii) For x > 0, taking ln: (ln 3)(ln 3 + ln x) = (ln 4)(ln 4 + ln x) ⇒ ln x (ln 3 − ln 4) = (ln 4)2 − (ln 3)2 ⇒ ln x = −ln 12 ⇒ x = 112 (note: x = 0 also satisfies 0b = 0 for b > 0).
(b) Graph Features:
• y = 2x: y-intercept (0, 1), horizontal asymptote y = 0 (as x → −∞). Reflection in y = x gives y = log2 x: x-intercept (1, 0), vertical asymptote x = 0.
• y = e−x and y = 110x both pass through (0, 1) with horizontal asymptote y = 0 (as x → ∞); 10−x is steeper for x < 0 and closer to the x-axis for x > 0.

Exam-Style Worked Example — Geometric Vectors, Collinearity & Area Ratios H2 Exam Style
Relative to an origin O, the points A and B have position vectors a and b respectively, where a and b are non-parallel. The point M is the midpoint of AB, and the point P lies on OB produced such that OB : BP = 2 : 1. The line segment AP intersects OM at X.
(a) Express OM⃗ and AP⃗ in terms of a and b.
(b) Given that OX⃗ = λOM⃗ and AX⃗ = μAP⃗, find the values of λ and μ.
(c) Hence show that O, X, M are collinear and find the ratio Area of ▵OAXArea of ▵OAP.

Since OB : BP = 2 : 1 on OB produced, OP⃗ = 32b ⇒ AP⃗ = OP⃗ − OA⃗ = 32b − a.

(b) Express OX⃗ in two ways:
• OX⃗ = λOM⃗ = λ2a + λ2b
• OX⃗ = OA⃗ + μAP⃗ = a + μ(32b − a) = (1 − μ)a + 3μ2b
Since a and b are non-parallel, equate coefficients:
λ2 = 1 − μ and λ2 = 3μ2 ⇒ 1 − μ = 3μ2 ⇒ μ = 25, λ = 65.

(c) Since OX⃗ = 65OM⃗ and O is a common point, O, X, M are collinear.
Since ▵OAX and ▵OAP share the same perpendicular height from O to line AP, and AX⃗ = 25AP⃗:

5.1 – 5.3 Properties & Graph Sketching

Absolute Value |f(x)| Rules

Definition: |x| = x if x ≥ 0, and −x if x < 0.
• |xy| = |x||y|;  |xy| = |x||y| (y ≠ 0)
• |x2| = |x|2 = x2;  √x2 = |x|
• For a > 0: |x| = a ⇔ x = ±a.
Sketching y = |f(x)|:
Retain the portion of y = f(x) on or above the x-axis (f(x) ≥ 0), and reflect the portion below the x-axis (f(x) < 0) upward across the x-axis (forming sharp corners at x-intercepts).
Worked Example — Modulus Bounds & Equations Sections 5.1 – 5.3
(a) Given x ∈ [−5, 3] and y ∈ [1, 6], find the largest and least values of: (i) |x − y|, (ii) |x + y|, (iii) |xy|, (iv) |x2y|.
(b) Solve: (i) |x2 − 2x − 3| = 5; (ii) |x2 − 2x − 3| = −1; (iii) |ln x| = 1; (iv) |ln x| = |2x2 − 2x − 3|.
(a) Bounds:
• (i) |x − y|: Largest at x = −5, y = 6 ⇒ 11; Least when x = y (e.g. 1) ⇒ 0.
• (ii) |x + y|: Largest at x = 3, y = 6 ⇒ 9; Least when x + y = 0 (e.g. x = −2, y = 2) ⇒ 0.
• (iii) |xy|: Largest at x = −5, y = 6 ⇒ 30; Least at x = 0 ⇒ 0.
• (iv) |x2y|: Largest at x = −5, y = 6 ⇒ 25 × 6 = 150; Least at x = 0 ⇒ 0.

(b) Equations:
• (i) x2 − 2x − 3 = 5 ⇒ (x − 4)(x + 2) = 0 ⇒ x = −2, 4 (and x2 − 2x − 3 = −5 has no real roots) ⇒ −2, 4.
• (ii) Modulus cannot be negative ⇒ no solution.
• (iii) ln x = ±1 ⇒ x = e−1, e ≈ 0.368, 2.72.
• (iv) By GC intersection of Y1 = |ln X| and Y2 = |2X2 − 2X − 3|: x ≈ 0.0456, 2.73, 3.28.
6.1 – 6.2 Differentiation & Stationary Points

Product Rule, Quotient Rule & Nature Tests

Product Rule: ddx(uv) = u dvdx + v dudx

Quotient Rule: ddx(uv) = v dudx − u dvdxv2
Stationary Points (dydx = 0):
• Local Maximum: d2ydx2 < 0 (or gradient changes + → 0 → −).
• Local Minimum: d2ydx2 > 0 (or gradient changes − → 0 → +).
• Stationary Point of Inflexion: gradient keeps same sign across stationary point.
Worked Example — Differentiation & Stationary Points Sections 6.1 – 6.2
(a) Differentiate with respect to x:
(i) y = x + (2a + 1) + (a + 1)2x − 1 (x ≠ 1, a > 0)
(ii) y = x2 − 4x + k2x − k (x ≠ k, k ≠ 0, 2)
(b) Find the exact coordinates of the stationary points on y = x2 + 94 − x (x ≠ 4) and determine their nature.
(a)(i) Treat a as a constant: dydx = 1 − (a + 1)2(x − 1)2.

(a)(ii) By Quotient Rule:
dydx = (x − k)(2x − 4) − (x2 − 4x + k2)(1)(x − k)2 = x2 − 2kx + 4k − k2(x − k)2.

(b) dydx = (4 − x)(2x) − (x2 + 9)(−1)(4 − x)2 = −x2 + 8x + 9(4 − x)2 = −(x − 9)(x + 1)(4 − x)2.
Setting dydx = 0 gives x = 9 or x = −1:
• At x = 9: y = 81 + 94 − 9 = −18. First derivative sign test around 9 (+ → 0 → −) ⇒ (9, −18) is a local maximum.
• At x = −1: y = 1 + 94 − (−1) = 2. First derivative sign test around −1 (− → 0 → +) ⇒ (−1, 2) is a local minimum.
